# Spring AI Odyssey

**A hands-on lab for Spring AI.** One feature per lab, each small enough to
read in a sitting and runnable on its own.

## About this project

Spring AI moves quickly, and the reference documentation is thorough but
necessarily abstract. This repository is the other half: a single working
application where every capability is exercised against a real example, so a
Java developer can clone it, run it, and see the feature working in under five
minutes.

## About Me

I am a Java engineer who works with Spring day to day, and I built this because
I wanted to experiment and understand Spring AI properlyand contribute to Spring Community. Each
iteration is written the way I would want to find it: the smallest amount of code that
demonstrates the feature, with the reasoning behind it visible rather than
assumed.

Spring AI is, to my mind, one of the most consequential things happening in the
Java ecosystem right now. The argument that generative AI belongs only to Python
was never a technical one, and Spring AI is the most credible answer to it. I
follow the project closely and intend to contribute back to it and to the wider
Spring community as this work continues.

Corrections, issues and pull requests are welcome — particularly from anyone who
knows these APIs better than I do.
